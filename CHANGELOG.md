# Changelog

## [0.1.0]

- Граматика SIPL, парсер і типізоване AST з позиціями в тексті.
- Інтерпретатор зі станом, лімітом кроків і подіями виконання.
- CLI: `parse`, `check`, `run`, `trace`, режим `--json`.
- Debug Adapter Protocol: breakpoints, continue, step, variables, evaluate.
- Розширення VS Code із запуском налагодження через F5.
